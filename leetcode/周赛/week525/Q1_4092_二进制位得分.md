# Q1 · 4092. 二进制位得分

- 难度：简单
- 分值：3
- [官方题目](https://leetcode.cn/contest/weekly-contest-525/problems/binary-digit-score/)

## 题目描述

输入两个正整数 `a` 和 `b`。分别统计它们的二进制表示中 `1` 的数量，记为 `s1` 和 `s2`。

按下列规则计算得分：

- 如果 `s1 >= s2`，得分等于 `s1 × s2`；
- 如果 `s1 < s2`，得分等于 `s2 ÷ s1`，采用整数除法。

输出最终得分。

## 案例

| 输入 | 二进制中 1 的个数 | 输出 | 计算 |
| --- | --- | --- | --- |
| `a = 14, b = 6` | `3, 2` | `6` | `3 × 2` |
| `a = 5, b = 15` | `2, 4` | `2` | `4 ÷ 2` |
| `a = 10, b = 12` | `2, 2` | `4` | `2 × 2` |

## 数据范围

`1 <= a, b <= 100`.
