# Q4 · 4095. 统计频次阶梯子数组的数目 II

- 难度：困难
- 分值：6
- [官方题目](https://leetcode.cn/contest/weekly-contest-525/problems/count-frequency-staircase-subarrays-ii/)

## 题目描述

给定整数数组 `nums`，计算其中满足“频次阶梯”条件的非空连续子数组数量。

判定方式与 Q3 相同：先按元素的首次出现顺序列出所有不同值。若一共出现 `k` 种值，且它们的出现次数依次精确为 `1, 2, ..., k`，这个子数组便计入答案。

例如，`[5,8,8,2,2,2]` 的不同元素依次为 5、8、2，频次是 `[1,2,3]`，因此符合条件。

## 案例

- `nums = [5,8,8,2,2,2]`，答案为 `9`。
- `nums = [6,6,9,9]`，答案为 `5`。
- `nums = [2,3,4,4,3,4]`，答案为 `8`。

## 与 Q3 的区别

题意不变，但本题将数组长度扩大到 `5 × 10^4`。枚举全部子数组的做法不再可行，需要利用更高效的数据结构或统计方法。

## 数据范围

- `1 <= nums.length <= 5 × 10^4`
- `1 <= nums[i] <= 10^5`
