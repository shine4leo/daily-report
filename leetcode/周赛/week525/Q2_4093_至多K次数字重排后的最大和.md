# Q2 · 4093. 至多 K 次数字重排后的最大和

- 难度：中等
- 分值：4
- [官方题目](https://leetcode.cn/contest/weekly-contest-525/problems/maximize-sum-after-at-most-k-digit-rearrangements/)

## 题意摘要

给定整数数组 `nums` 和 `k`。一次操作可以选定数组中的一个数，并任意重排它的十进制数字，得到一个新整数。最多进行 `k` 次操作，求数组元素和的最大值。

## 解题思路

对每个数，将其数字按降序排列即可得到一次重排后的最大值；该数对总和的最大增益为“重排后的最大值减去原值”。

收集所有增益并按降序排列，初始答案为原数组之和，再累加最大的至多 `k` 个正增益。由于每个元素最多操作一次、操作之间互不影响，选择最大的正增益即可得到最优结果。

```cpp
class Solution {
public:
    vector<long long> res;

    long long maximizeSum(vector<int>& nums, int k) {
        for (long long x : nums) {
            string s = to_string(x);
            sort(s.rbegin(), s.rend());
            long long mx = stoll(s);
            res.push_back(mx - x);
        }

        sort(res.rbegin(), res.rend());

        long long ans = 0;
        for (int x : nums) {
            ans += x;
        }

        for (int i = 0; i < k && i < res.size(); i++) {
            if (res[i] > 0) ans += res[i];
        }

        return ans;
    }
};
```

- 时间复杂度：`O(n · d log d + n log n)`，其中 `d` 为单个数字的位数。
- 空间复杂度：`O(n)`。

## 约束

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= nums.length`
