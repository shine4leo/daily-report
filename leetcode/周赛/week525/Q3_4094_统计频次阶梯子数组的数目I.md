# Q3 · 4094. 统计频次阶梯子数组的数目 I

- 难度：中等
- 分值：5
- [官方题目](https://leetcode.cn/contest/weekly-contest-525/problems/count-frequency-staircase-subarrays-i/)

## 题意摘要

统计 `nums` 中满足“频次阶梯”条件的非空连续子数组。将子数组中不同值按首次出现顺序排列；若共有 `k` 个不同值，第 `i` 个值恰好出现 `i` 次（频次数列为 `1, 2, ..., k`），该子数组即为有效。

返回有效子数组的数量。

## 约束

- `1 <= nums.length <= 1500`
- `1 <= nums[i] <= 10^5`
