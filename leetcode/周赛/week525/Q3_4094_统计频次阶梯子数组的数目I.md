# Q3 · 4094. 统计频次阶梯子数组的数目 I

- 难度：中等
- 分值：5
- [官方题目](https://leetcode.cn/contest/weekly-contest-525/problems/count-frequency-staircase-subarrays-i/)

## 题目描述

给定整数数组 `nums`，统计其中有多少个非空连续子数组满足“频次阶梯”条件。

对一个子数组，按各数值**第一次出现的先后顺序**列出不同元素。若有 `k` 个不同元素，并且第 1 个元素出现 1 次、第 2 个元素出现 2 次，直到第 `k` 个元素出现 `k` 次，则该子数组有效。

例如，`[5, 8, 8]` 中 5 先出现且仅出现一次，8 后出现且出现两次，因此它的频次数列为 `[1, 2]`，符合条件。

## 案例

- `nums = [5, 8, 8, 2, 2, 2]`，结果为 `9`：6 个单元素子数组都有效；另外 `[5,8,8]`、`[8,2,2]` 和整个数组的频次数列也分别为 `[1,2]`、`[1,2]`、`[1,2,3]`。
- `nums = [6, 6, 9, 9]`，结果为 `5`：4 个单元素子数组，加上 `[6,9,9]`。
- `nums = [2, 3, 4, 4, 3, 4]`，结果为 `8`：6 个单元素子数组，再加上 `[3,4,4]` 和整个数组。

## 数据范围

- `1 <= nums.length <= 1500`
- `1 <= nums[i] <= 10^5`
