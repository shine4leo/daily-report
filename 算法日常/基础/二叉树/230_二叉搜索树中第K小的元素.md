# 230. 二叉搜索树中第 K 小的元素

- 题目链接：[LeetCode 230](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)
- 分类：二叉树递归 · 前序 / 中序 / 后序
- 标签：二叉搜索树、中序遍历、DFS
- 状态：已完成

## 题意

给定二叉搜索树根节点 `root` 和从 `1` 开始计数的整数 `k`，返回树中第 `k` 小的节点值。

## 思路：中序遍历得到升序序列

二叉搜索树满足：

```text
左子树的值 < 根节点的值 < 右子树的值
```

按照“左子树 → 根节点 → 右子树”的中序遍历顺序访问 BST，节点值恰好是递增的。

因此：

1. 中序遍历，将节点值依次加入 `ans`。
2. `ans[0]` 是第 `1` 小，`ans[k - 1]` 就是第 `k` 小。

## 代码

```cpp
class Solution {
public:
    void zhongxu(TreeNode* root, vector<int>& ans) {
        if (root == nullptr) {
            return;
        }

        zhongxu(root->left, ans);
        ans.push_back(root->val);
        zhongxu(root->right, ans);
    }

    int kthSmallest(TreeNode* root, int k) {
        vector<int> ans;

        zhongxu(root, ans);

        // k 从 1 开始计数，vector 下标从 0 开始
        return ans[k - 1];
    }
};
```

## 复杂度

- 时间复杂度：`O(n)`，需要遍历所有 `n` 个节点。
- 空间复杂度：`O(n)`，`ans` 最坏保存所有节点值；递归栈额外为 `O(h)`，`h` 为树高。

## 可优化方向

当前写法会遍历整棵树并保存所有值。若只需要第 `k` 小元素，可以在中序遍历过程中计数：

- 每访问一个节点，`k--`。
- 当 `k == 0` 时立刻记录或返回当前值。
- 不需要保存完整的 `ans` 数组。

不过本题当前代码逻辑清晰，适合先掌握 BST 中序遍历有序这一性质。

## 易错点

- `k` 从 `1` 开始，数组下标从 `0` 开始，所以答案是 `ans[k - 1]`。
- 只有对二叉搜索树做中序遍历，才保证结果有序；普通二叉树不具备这一性质。
