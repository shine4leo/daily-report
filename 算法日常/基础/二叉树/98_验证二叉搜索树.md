# 98. 验证二叉搜索树

- 题目链接：[LeetCode 98](https://leetcode.cn/problems/validate-binary-search-tree/)
- 标签：二叉树、DFS、递归、二叉搜索树
- 状态：已完成

## 题意

判断给定二叉树是否为有效二叉搜索树（BST）：

- 左子树的所有节点都严格小于当前节点。
- 右子树的所有节点都严格大于当前节点。
- 左右子树本身也必须是有效 BST。

## 思路：递归维护节点允许的取值范围

不能只比较“当前节点与左右孩子”的大小。例如，某个节点即使小于父节点，也可能仍大于更上层祖先，从而违反 BST 的定义。

因此，递归时为每个节点维护一个开区间 `(lo, hi)`：

- 根节点的范围是 `(LLONG_MIN, LLONG_MAX)`。
- 左子树所有节点必须小于当前节点：递归左子树时范围变为 `(lo, root->val)`。
- 右子树所有节点必须大于当前节点：递归右子树时范围变为 `(root->val, hi)`。
- 节点值不在开区间内，立刻返回 `false`。

使用 `long long` 边界而不是 `int`，避免节点值恰好等于 `INT_MIN` 或 `INT_MAX` 时出现边界冲突。

## 代码

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return dfs(root, LLONG_MIN, LLONG_MAX);
    }

    bool dfs(TreeNode* root, long long lo, long long hi) {
        if (root == nullptr) {
            return true;
        }

        // BST 要求严格小于或严格大于，不允许重复值
        if (root->val <= lo || root->val >= hi) {
            return false;
        }

        bool leftValid = dfs(root->left, lo, root->val);
        bool rightValid = dfs(root->right, root->val, hi);

        return leftValid && rightValid;
    }
};
```

## 递归范围示例

假设根节点为 `5`：

```text
5 的合法范围：(-∞, +∞)
左子树的合法范围：(-∞, 5)
右子树的合法范围：(5, +∞)
```

若左孩子是 `4`，则它的右子树范围是 `(4, 5)`。即使某个节点比 `4` 大，只要它大于等于 `5`，仍然不合法。

## 复杂度

- 时间复杂度：`O(n)`，每个节点访问一次。
- 空间复杂度：`O(h)`，递归栈深度为树高 `h`；最坏情况下为 `O(n)`。

## 易错点

- BST 要求**严格**大小关系，重复值不合法。
- 不能只比较当前节点与其直接左右孩子。
- 上下界必须来自祖先路径，而不是只来自当前父节点。
