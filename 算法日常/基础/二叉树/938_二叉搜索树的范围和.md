# 938. 二叉搜索树的范围和

- 题目链接：[LeetCode 938](https://leetcode.cn/problems/range-sum-of-bst/)
- 分类：二叉树递归 · 前序 / 中序 / 后序
- 标签：二叉搜索树、DFS、剪枝
- 状态：已完成

## 题意

给定二叉搜索树根节点 `root` 和范围 `[low, high]`，返回所有满足：

```text
low <= 节点值 <= high
```

的节点值之和。

## 思路：利用 BST 性质剪枝

二叉搜索树满足：

- 左子树所有值小于当前节点。
- 右子树所有值大于当前节点。

因此遍历到当前节点时可以做三种判断：

1. `root->val < low`  
   当前节点和整棵左子树都小于 `low`，无需继续搜索左边，只递归右子树。

2. `root->val > high`  
   当前节点和整棵右子树都大于 `high`，无需继续搜索右边，只递归左子树。

3. `low <= root->val <= high`  
   当前节点计入答案，并继续搜索左右子树。

这是一种带剪枝的 DFS。若忽略 BST 性质，当然也可以遍历所有节点后筛选，但会失去可以跳过整棵子树的优势。

## 代码

```cpp
class Solution {
public:
    int rangeSumBST(TreeNode* root, int low, int high) {
        if (!root) {
            return 0;
        }

        if (root->val < low) {
            // 左子树全部更小，不可能落入范围
            return rangeSumBST(root->right, low, high);
        }

        if (root->val > high) {
            // 右子树全部更大，不可能落入范围
            return rangeSumBST(root->left, low, high);
        }

        // 当前节点在范围内，继续搜索左右子树
        return root->val
             + rangeSumBST(root->left, low, high)
             + rangeSumBST(root->right, low, high);
    }
};
```

## 复杂度

- 时间复杂度：最坏为 `O(n)`；剪枝生效时，实际访问节点数会更少。
- 空间复杂度：`O(h)`，递归栈深度为树高 `h`；最坏为 `O(n)`。

## 易错点

- 范围是闭区间，等于 `low` 或 `high` 的节点也要计入。
- 判断 `root->val < low` 时，只能剪掉左子树；右子树仍可能有合法节点。
- 判断 `root->val > high` 时，只能剪掉右子树；左子树仍可能有合法节点。
