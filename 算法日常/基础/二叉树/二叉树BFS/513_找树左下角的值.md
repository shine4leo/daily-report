# 513. 找树左下角的值

- 题目链接：[LeetCode 513](https://leetcode.cn/problems/find-bottom-left-tree-value/)
- 标签：二叉树、BFS、DFS
- 状态：已完成

## 题意

给定二叉树根节点 `root`，返回最底层、最左侧节点的值。

关键是同时满足两个条件：

1. 节点的深度最大。
2. 在这一最深层中，它最靠左。

下面对比三种可行思路。

## 方案一：BFS 保存每一层所有节点值

普通层序遍历，把每层的节点值都保存到 `res`。遍历结束后，最后一层的第一个元素就是答案：

```cpp
return res.back()[0];
```

### 为什么正确

BFS 一层层从左到右处理节点，`res.back()` 是最深层，`res.back()[0]` 是该层最左节点。

### 评价

实现直观，但为了只返回一个整数，额外保存了整棵树的所有节点值，空间并不必要。

```cpp
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> q;
        vector<vector<int>> res;

        q.push(root);

        while (!q.empty()) {
            int size = q.size();
            vector<int> temp;

            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front();
                q.pop();

                temp.push_back(node->val);

                if (node->left) {
                    q.push(node->left);
                }
                if (node->right) {
                    q.push(node->right);
                }
            }

            res.push_back(temp);
        }

        return res.back()[0];
    }
};
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，队列与 `res` 最坏都可能达到 `O(n)`

## 方案二：BFS 仅记录每层的第一个节点（推荐 BFS 写法）

不再保存所有层的结果。每一层开始时，队列的第一个节点就是这一层最左节点：

- 每层的 `i == 0` 时更新 `result`。
- 当 BFS 结束，最后一次更新来自最深层的最左节点。

### 为什么正确

二叉树层序遍历中，父节点按从左到右出队；每个父节点又先入队左孩子、再入队右孩子。所以每层队列中的第一个节点一定是这一层最左节点。

```cpp
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);

        int result = root->val;

        while (!q.empty()) {
            int size = q.size();

            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front();
                q.pop();

                if (i == 0) {
                    result = node->val;
                }

                if (node->left) {
                    q.push(node->left);
                }
                if (node->right) {
                    q.push(node->right);
                }
            }
        }

        return result;
    }
};
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(w)`，`w` 是树的最大宽度，最坏为 `O(n)`
- 优点：不需要保存每层数组，最适合本题的 BFS 解法

## 方案三：DFS 前序遍历，始终先左后右

DFS 也能解决。维护当前见过的最大深度 `maxDepth` 和答案 `result`：

- 采用“根 → 左 → 右”的先序遍历。
- 第一次到达某个更深层时，访问到的一定是该层最左节点。
- 只有 `depth > maxDepth` 才更新答案；同一层后续节点不会覆盖答案。

### 为什么正确

由于始终先递归左子树，DFS 第一次到达深度 `d` 时，必然先经过这一层最靠左的路径。因此第一次抵达最深深度时保存的节点就是所求节点。

```cpp
class Solution {
public:
    int maxDepth = -1;
    int result = 0;

    int findBottomLeftValue(TreeNode* root) {
        dfs(root, 0);
        return result;
    }

    void dfs(TreeNode* node, int depth) {
        if (!node) {
            return;
        }

        // 第一次到达更深层：先序遍历且左子树优先
        if (depth > maxDepth) {
            maxDepth = depth;
            result = node->val;
        }

        dfs(node->left, depth + 1);
        dfs(node->right, depth + 1);
    }
};
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，`h` 是树高；最坏退化为 `O(n)`

## 三种方案对比

| 方案 | 核心做法 | 额外信息 | 空间特点 | 适合场景 |
| --- | --- | --- | --- | --- |
| BFS 保存所有层 | 保存 `res`，取最后一层第一个值 | 所有层的节点值 | 较多 | 同时需要完整层序结果 |
| BFS 记录每层首节点 | 每层 `i == 0` 更新答案 | 一个 `result` | 只保留队列 | 本题推荐的 BFS 解法 |
| DFS 左优先 | 首次到达更深层时更新答案 | 最大深度和答案 | 递归栈 | 熟悉递归、需要顺带处理深度信息 |

> 如果只求本题答案，方案二最直接；如果正在练习递归和“先左后右”的遍历顺序，方案三很值得掌握。
