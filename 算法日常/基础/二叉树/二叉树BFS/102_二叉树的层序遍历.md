# 102. 二叉树的层序遍历

- 题目链接：[LeetCode 102](https://leetcode.cn/problems/binary-tree-level-order-traversal/)
- 标签：二叉树、BFS、队列
- 状态：已完成

## 思路

层序遍历使用队列：

1. 根节点先入队。
2. 每轮先记录当前队列长度 `size`，它恰好等于当前层的节点数。
3. 连续弹出 `size` 个节点，收集节点值；同时把它们的左右孩子加入队列。
4. 当前层收集完毕后，将结果加入答案。

注意：孩子节点会在本层遍历期间进入队列，但不会被当前轮处理，因为循环次数提前固定为 `size`。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (root == nullptr) {
            return {};
        }

        queue<TreeNode*> q;
        vector<vector<int>> res;

        q.push(root);

        while (!q.empty()) {
            int size = q.size();
            vector<int> temp;

            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front();
                q.pop();

                temp.push_back(node->val);

                if (node->left) {
                    q.push(node->left);
                }
                if (node->right) {
                    q.push(node->right);
                }
            }

            res.push_back(temp);
        }

        return res;
    }
};
```

## 复杂度

- 时间复杂度：`O(n)`，每个节点进出队各一次。
- 空间复杂度：`O(n)`，最坏情况下队列和答案都可能保存 `n` 个节点值。
