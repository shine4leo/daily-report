# 103. 二叉树的锯齿形层序遍历

- 题目链接：[LeetCode 103](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/)
- 标签：二叉树、BFS、队列
- 状态：已完成

## 思路

先按普通 BFS 从左到右收集每一层节点：

- 偶数层保持原顺序。
- 奇数层将当前层数组反转。
- 用 `count` 记录当前层编号，`count % 2 != 0` 时反转。

队列中孩子仍始终按“左孩子、右孩子”入队；只反转结果数组，不改变下一层的遍历顺序，因此逻辑更清晰。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        if (root == nullptr) {
            return {};
        }

        queue<TreeNode*> q;
        vector<vector<int>> res;

        q.push(root);
        int count = 0;

        while (!q.empty()) {
            int size = q.size();
            vector<int> temp;

            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front();
                q.pop();

                temp.push_back(node->val);

                if (node->left) {
                    q.push(node->left);
                }
                if (node->right) {
                    q.push(node->right);
                }
            }

            if (count % 2 != 0) {
                reverse(temp.begin(), temp.end());
            }

            count++;
            res.push_back(temp);
        }

        return res;
    }
};
```

## 复杂度

- 时间复杂度：`O(n)`。各层反转的总元素数不超过 `n`。
- 空间复杂度：`O(n)`。
