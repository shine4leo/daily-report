# 2415. 反转二叉树的奇数层

- 题目链接：[LeetCode 2415](https://leetcode.cn/problems/reverse-odd-levels-of-binary-tree/)
- 标签：二叉树、BFS、层序遍历
- 状态：已完成

## 题意

给定一棵完美二叉树，根节点深度为 `0`。需要反转每个**奇数层**的节点值，树的结构和指针关系保持不变，最后返回根节点。

例如深度为 `3` 的一层节点值为：

```text
[2, 1, 3, 4, 7, 11, 29, 18]
```

反转节点值后变为：

```text
[18, 29, 11, 7, 4, 3, 1, 2]
```

## 思路：BFS 按层收集节点指针

1. 使用队列进行层序遍历。
2. 每层先记录队列大小 `n`，并将这 `n` 个节点指针保存在 `temp` 中。
3. 若当前深度为奇数，则交换 `temp[i]` 与 `temp[n - 1 - i]` 的 `val`。
4. 只交换节点值，不交换节点指针，因此树的结构不变。
5. 每处理完一层，深度加一。

队列中节点始终按从左到右的顺序出队，所以 `temp` 的两端正好是一层中互为镜像位置的节点。

## 代码

```cpp
class Solution {
public:
    TreeNode* reverseOddLevels(TreeNode* root) {
        if (root == nullptr) {
            return root;
        }

        queue<TreeNode*> q;
        q.push(root);

        int depth = 0;

        while (!q.empty()) {
            int n = q.size();
            vector<TreeNode*> temp;

            for (int i = 0; i < n; i++) {
                TreeNode* node = q.front();
                q.pop();

                temp.push_back(node);

                if (node->left) {
                    q.push(node->left);
                }
                if (node->right) {
                    q.push(node->right);
                }
            }

            // 根节点深度为 0，因此 1、3、5... 层是奇数层
            if (depth % 2 != 0) {
                for (int i = 0; i < n / 2; i++) {
                    swap(temp[i]->val, temp[n - i - 1]->val);
                }
            }

            depth++;
        }

        return root;
    }
};
```

## 复杂度

- 时间复杂度：`O(n)`。每个节点只会入队、出队一次。
- 空间复杂度：`O(n)`。队列和单层的 `temp` 最坏都可能保存 `O(n)` 个节点。

## 易错点

- 题目要求反转的是**节点值**，不是把左右子树或节点指针真正交换。
- 根节点的层数是 `0`，所以要在 `depth % 2 != 0` 时处理。
- 交换循环只需进行 `n / 2` 次。
