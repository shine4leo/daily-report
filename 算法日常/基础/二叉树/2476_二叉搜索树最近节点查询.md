# 2476. 二叉搜索树最近节点查询

- 题目链接：[LeetCode 2476](https://leetcode.cn/problems/closest-nodes-queries-in-a-binary-search-tree/)
- 分类：二叉树递归 · 前序 / 中序 / 后序
- 标签：二叉搜索树、中序遍历、二分查找
- 状态：待优化

## 题意

给定一棵二叉搜索树和若干查询值 `queries[i]`，对每个查询返回：

- `mini`：树中小于等于查询值的最大节点值。
- `maxi`：树中大于等于查询值的最小节点值。
- 对应值不存在时返回 `-1`。

## 原思路：中序遍历后逐个扫描

你的中序遍历是正确的：BST 的中序遍历结果一定是升序数组。

但对每个查询都从头扫描整个数组，单次查询需要 `O(m)`，其中 `m` 是节点数；总时间达到 `O(mq)`，在节点数和查询数都较大时会超时。

```cpp
// 对每个 query 逐个扫描 ans，时间复杂度 O(mq)
for (int x : queries) {
    int a = -1;
    int b = -1;

    for (int v : ans) {
        if (v <= x) {
            a = v;
        }
        if (v >= x) {
            b = v;
            break;
        }
    }

    res.push_back({a, b});
}
```

## 优化思路：中序遍历 + 二分查找

中序遍历得到升序数组 `values` 后：

- `upper_bound(values, x)` 找到第一个 **大于** `x` 的位置。它前一个元素就是小于等于 `x` 的最大值，即 `mini`。
- `lower_bound(values, x)` 找到第一个 **大于等于** `x` 的位置。该元素就是 `maxi`。

这样每个查询只需两次二分查找。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> closestNodes(TreeNode* root, vector<int>& queries) {
        vector<int> values;

        // BST 中序遍历：得到严格递增数组
        dfs(root, values);

        vector<vector<int>> res;

        for (int x : queries) {
            // 第一个 > x 的位置；其前一个是 <= x 的最大值
            auto upper = upper_bound(values.begin(), values.end(), x);
            int mini = (upper == values.begin()) ? -1 : *prev(upper);

            // 第一个 >= x 的位置
            auto lower = lower_bound(values.begin(), values.end(), x);
            int maxi = (lower == values.end()) ? -1 : *lower;

            res.push_back({mini, maxi});
        }

        return res;
    }

    void dfs(TreeNode* root, vector<int>& values) {
        if (root == nullptr) {
            return;
        }

        dfs(root->left, values);
        values.push_back(root->val);
        dfs(root->right, values);
    }
};
```

## 查询示例

若中序数组为：

```text
values = [2, 4, 6, 8]
```

| 查询值 `x` | `mini` | `maxi` |
| --- | --- | --- |
| `1` | `-1` | `2` |
| `4` | `4` | `4` |
| `5` | `4` | `6` |
| `10` | `8` | `-1` |

## 复杂度

设树有 `m` 个节点，查询数为 `q`：

- 中序遍历：`O(m)`
- 每次查询：`O(log m)`
- 总时间复杂度：`O(m + q log m)`
- 空间复杂度：`O(m)`，用于保存中序数组；递归栈额外为 `O(h)`

## 易错点

- `lower_bound` 用于找 `maxi`，因为需要第一个 `>= x` 的值。
- `upper_bound` 的前一个位置用于找 `mini`，因为需要最后一个 `<= x` 的值。
- 使用 `prev(upper)` 前必须先判断 `upper != values.begin()`。
