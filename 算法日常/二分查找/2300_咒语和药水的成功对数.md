# 2300. 咒语和药水的成功对数

- 难度：中等
- 主题：二分查找、排序
- [官方题目](https://leetcode.cn/problems/successful-pairs-of-spells-and-potions/)

## 题目描述

给定正整数数组 `spells` 与 `potions`，以及阈值 `success`。

对每个咒语 `spells[i]`，统计有多少瓶药水 `potions[j]` 满足：

```text
spells[i] × potions[j] >= success
```

返回数组 `pairs`，其中 `pairs[i]` 是能与第 i 个咒语构成成功组合的药水数。

## 案例

| 输入 | 输出 |
| --- | --- |
| `spells = [5,1,3], potions = [1,2,3,4,5], success = 7` | `[4,0,3]` |
| `spells = [3,1,2], potions = [8,5,8], success = 16` | `[2,0,2]` |

## 方法 1：暴力枚举

对每个咒语枚举全部药水，直接检查乘积是否达到 `success`。

```cpp
class Solution {
public:
    vector<int> successfulPairs(vector<int>& spells, vector<int>& potions, long long success) {
        int n = spells.size();
        int m = potions.size();

        vector<int> successList;

        for (int x : spells) {
            int count = 0;

            for (int y : potions) {
                if ((long long)x * y >= success) {
                    count++;
                }
            }

            successList.push_back(count);
        }

        return successList;
    }
};
```

- 时间复杂度：`O(nm)`。
- 空间复杂度：`O(n)`，用于返回结果。
- 当 `n, m` 都接近 `10^5` 时会超时。

## 方法 2：排序 + 二分查找

先将 `potions` 升序排序。固定一个咒语 `x` 后，谓词

```text
x × potions[mid] >= success
```

随着 `mid` 增大，只会从假变为真。因此可以二分找出第一个成功药水的位置 `first`：

- `first` 左侧均失败；
- 从 `first` 到末尾均成功；
- 成功药水数量为 `m - first`。

乘积可能超过 `int` 范围，因此比较时使用 `long long`。

```cpp
class Solution {
public:
    vector<int> successfulPairs(vector<int>& spells, vector<int>& potions, long long success) {
        sort(potions.begin(), potions.end());

        int n = spells.size();
        int m = potions.size();
        vector<int> successList;

        for (int x : spells) {
            int left = 0;
            int right = m - 1;
            int first = m;

            while (left <= right) {
                int mid = left + (right - left) / 2;

                if ((long long)x * potions[mid] >= success) {
                    first = mid;
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }

            successList.push_back(m - first);
        }

        return successList;
    }
};
```

- 时间复杂度：`O(m log m + n log m)`。
- 空间复杂度：`O(n)`，不计排序实现可能使用的额外空间。

## 数据范围

- `1 <= spells.length, potions.length <= 10^5`
- `1 <= spells[i], potions[i] <= 10^5`
- `1 <= success <= 10^10`
