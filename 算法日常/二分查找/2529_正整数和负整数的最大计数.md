# 2529. 正整数和负整数的最大计数

- 难度：简单
- 主题：二分查找、边界查找
- [官方题目](https://leetcode.cn/problems/maximum-count-of-positive-integer-and-negative-integer/)

## 题目要求

给定一个按非递减顺序排列的数组 `nums`，返回其中正整数数量和负整数数量的较大值。

注意：

- `0` 既不是正数，也不是负数；
- 进阶要求是使用 `O(log n)` 时间复杂度。

## 案例

| 输入 | 正数个数 | 负数个数 | 输出 |
| --- | ---: | ---: | ---: |
| `[-2,-1,-1,1,2,3]` | 3 | 3 | 3 |
| `[-3,-2,-1,0,0,1,2]` | 2 | 3 | 3 |
| `[5,20,66,1314]` | 4 | 0 | 4 |

## 我的解答：两次边界二分

有序数组可分为三段：负数、零、正数。

1. 找第一个大于等于 `0` 的位置 `first`：
   - 其左边全部为负数，所以负数数量是 `first`。
2. 找第一个大于 `0` 的位置 `last`：
   - 从 `last` 到末尾全部为正数，所以正数数量是 `n - last`。

如果某个边界不存在，就将其视为 `n`；这样相应的数量自然为 `0`。

```cpp
class Solution {
public:
    int maximumCount(vector<int>& nums) {
        int n = nums.size();
        int first = n;
        // 如果不存在第一个非负数，则认为边界在数组末尾。
        int last = n;

        int left = 0;
        int right = n - 1;

        // 找第一个大于等于 0 的位置。
        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] >= 0) {
                first = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        left = 0;
        right = n - 1;

        // 找第一个大于 0 的位置。
        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > 0) {
                last = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        int x = first;
        int y = n - last;
        return (x > y) ? x : y;
    }
};
```

## 数据范围

- `1 <= nums.length <= 2000`
- `-2000 <= nums[i] <= 2000`
- `nums` 按非递减顺序排列

## 复杂度

- 时间复杂度：`O(log n)`，执行两次二分查找。
- 空间复杂度：`O(1)`。
