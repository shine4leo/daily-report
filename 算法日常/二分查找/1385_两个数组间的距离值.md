# 1385. 两个数组间的距离值

- 难度：简单
- 主题：二分查找、排序、数组
- [官方题目](https://leetcode.cn/problems/find-the-distance-value-between-two-arrays/)

## 题目描述

给定整数数组 `arr1`、`arr2` 和整数 `d`。

对于 `arr1` 中的元素 `x`，如果不存在任何 `arr2` 中的元素 `y` 满足：

```text
|x - y| <= d
```

则 `x` 计入距离值。返回所有满足条件的 `arr1` 元素数量。

换句话说，需要判断 `arr2` 中是否存在元素落在闭区间 `[x - d, x + d]` 内。

## 案例

| 输入 | 输出 |
| --- | ---: |
| `arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2` | 2 |
| `arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3` | 2 |
| `arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6` | 1 |

## 方法 1：暴力枚举

对 `arr1` 的每个元素 `x`，逐个检查 `arr2`。一旦找到 `|x-y| <= d` 的元素，就可以提前退出，因为 `x` 已不满足要求。

```cpp
class Solution {
public:
    int findTheDistanceValue(vector<int>& arr1, vector<int>& arr2, int d) {
        int count = 0;

        for (int x : arr1) {
            bool isValue = true;

            for (int y : arr2) {
                if (abs(x - y) <= d) {
                    isValue = false;
                    break;
                }
            }

            if (isValue == true) count++;
        }

        return count;
    }
};
```

- 时间复杂度：最坏为 `O(nm)`。
- 空间复杂度：`O(1)`。

## 方法 2：排序 + 二分查找

先将 `arr2` 升序排序。对于每个 `x`，二分找出第一个大于等于 `x-d` 的元素位置 `first`：

- 若 `first == m`，说明 `arr2` 所有元素都小于 `x-d`；
- 若 `arr2[first] > x+d`，说明第一个不小于 `x-d` 的元素也已超过区间右端；
- 两种情况都表示 `[x-d, x+d]` 中不存在 `arr2` 元素，因此 `x` 计入答案。

```cpp
class Solution {
public:
    int findTheDistanceValue(vector<int>& arr1, vector<int>& arr2, int d) {
        sort(arr2.begin(), arr2.end());

        int count = 0;
        int m = arr2.size();

        for (int x : arr1) {
            int left = 0;
            int right = m - 1;
            int first = m;

            // 找到第一个 >= x - d 的元素。
            while (left <= right) {
                int mid = left + (right - left) / 2;

                if (arr2[mid] >= x - d) {
                    first = mid;
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }

            // 判断是否存在元素落在 [x-d, x+d] 内。
            if (first == m || arr2[first] > x + d) {
                count++;
            }
        }

        return count;
    }
};
```

- 时间复杂度：`O(m log m + n log m)`。
- 空间复杂度：取决于排序实现；除排序外为 `O(1)`。

## 为什么暴力法实测可能更快？

本题中 `arr1.length` 和 `arr2.length` 最大只有 500。带 `break` 的暴力解在经常早早发现不符合条件时，实际比较次数会远少于 `n × m`。

二分法还需要先排序，且每个元素都有多次循环与分支。数据规模很小时，这些固定开销可能超过暴力枚举，因此出现“暴力 1 ms、二分 3 ms”是正常的。复杂度描述的是数据规模扩大后的增长趋势，单次运行时间也会受到测试数据、编译器和测量误差影响。

## 数据范围

- `1 <= arr1.length, arr2.length <= 500`
- `-10^3 <= arr1[i], arr2[j] <= 10^3`
- `0 <= d <= 100`
