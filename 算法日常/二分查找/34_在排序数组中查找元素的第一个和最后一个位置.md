# 34. 在排序数组中查找元素的第一个和最后一个位置

- 难度：中等
- 主题：二分查找、边界查找
- [官方题目](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

## 题目要求

给定一个按**非递减顺序**排列的整数数组 `nums` 和目标值 `target`，找出目标值在数组中的第一个位置与最后一个位置。

- 若目标值不存在，返回 `[-1, -1]`；
- 必须使用时间复杂度为 `O(log n)` 的算法；
- 数组允许出现重复元素，因此不能在找到任意一个 `target` 后立即结束。

## 案例

| 输入 | 输出 |
| --- | --- |
| `nums = [5,7,7,8,8,10], target = 8` | `[3,4]` |
| `nums = [5,7,7,8,8,10], target = 6` | `[-1,-1]` |
| `nums = [], target = 0` | `[-1,-1]` |

## 我的解答：两次二分查找

第一次二分查找左边界：

- 找到 `target` 时记录当前位置；
- 继续向左半段搜索，即令 `right = mid - 1`。

第二次二分查找右边界：

- 找到 `target` 时记录当前位置；
- 继续向右半段搜索，即令 `left = mid + 1`。

两次二分都没有找到目标值时，初始值 `-1` 会保留下来。

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int n = nums.size();
        if (nums.size() == 0) return {-1, -1};

        int first = -1;
        int last = -1;

        int left = 0;
        int right = n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                first = mid;
                right = mid - 1;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        left = 0;
        right = n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                last = mid;
                left = mid + 1;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return {first, last};
    }
};
```

## 数据范围

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` 按非递减顺序排列

## 复杂度

- 时间复杂度：`O(log n)`，执行两次二分查找。
- 空间复杂度：`O(1)`，不计返回数组。
