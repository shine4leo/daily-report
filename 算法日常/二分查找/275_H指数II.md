# 275. H 指数 II

- 难度：中等
- 主题：二分查找、数组
- [官方题目](https://leetcode.cn/problems/h-index-ii/)

## 题目要求

给定按升序排列的数组 `citations`，其中 `citations[i]` 是第 i 篇论文的引用次数。

H 指数是最大的整数 `h`，满足：

- 至少有 `h` 篇论文的引用次数不少于 `h`。

本题额外要求设计 `O(log n)` 时间复杂度的算法。

## 案例

| 输入 | 输出 | 说明 |
| --- | ---: | --- |
| `[0,1,3,5,6]` | 3 | 有 3 篇论文的引用次数至少为 3 |
| `[1,2,100]` | 2 | 有 2 篇论文的引用次数至少为 2 |

## 我的解答：线性扫描

数组已升序排列。对于下标 `i`：

- 从 `i` 到末尾共有 `n - i` 篇论文；
- 这些论文的引用次数都不小于 `citations[i]`；
- 当 `citations[i] >= n - i` 时，`n - i` 是一个可行的 H 指数候选值。

遍历全部下标并维护最大候选值即可。

```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int h = 0;
        int n = citations.size();

        for (int i = 0; i < n; i++) {
            int x = citations[i];

            if (x >= n - i) {
                h = max(h, n - i);
            }
        }

        return h;
    }
};
```

## 关于题目复杂度要求

这份代码结果正确，但时间复杂度为 `O(n)`，因此它属于线性扫描解法，**不满足题目要求的 `O(log n)`**。

由于条件 `citations[i] >= n - i` 随着下标增大具有单调性，可以在后续使用二分查找第一个满足条件的位置，将时间复杂度降为 `O(log n)`。

## 数据范围

- `1 <= citations.length <= 10^5`
- `0 <= citations[i] <= 1000`
- `citations` 按升序排列

## 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。
