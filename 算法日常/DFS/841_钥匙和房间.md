# 841. 钥匙和房间

- 难度：中等
- 主题：DFS、图、可达性
- [官方题目](https://leetcode.cn/problems/keys-and-rooms/)

## 题目描述

有 `n` 个房间，编号为 `0` 到 `n - 1`。开始时只能进入 0 号房间，其余房间都处于上锁状态。

进入一个房间后，可以获得该房间内的所有钥匙。钥匙上的编号表示它能打开的房间。数组 `rooms` 中的 `rooms[i]` 即进入 i 号房间后能取得的全部钥匙。

判断从 0 号房间开始，是否能够最终访问全部房间：

- 全部可访问，返回 `true`；
- 存在无法进入的房间，返回 `false`。

这可以看作一张有向图：房间是节点，房间 i 中的一把钥匙 j 是一条从 i 到 j 的边。问题等价于从节点 0 出发能否遍历所有节点。

## 案例

### 案例 1

```text
rooms = [[1], [2], [3], []]
```

结果：`true`。

访问过程：从 0 号房间取得钥匙 1，随后依次进入 1、2、3 号房间，因此所有房间均可到达。

### 案例 2

```text
rooms = [[1,3], [3,0,1], [2], [0]]
```

结果：`false`。

说明：从 0 号房间可继续到达 1 和 3，但无法取得 2 号房间的钥匙。

## DFS 解题方向

从房间 0 开始执行深度优先遍历：

1. 标记当前房间已访问；
2. 枚举该房间内的每一把钥匙；
3. 对尚未访问的目标房间继续 DFS；
4. 遍历结束后，检查已访问房间数是否等于 `n`。

## 我的解答

```cpp
class Solution {
public:
    void dfs(vector<vector<int>>& rooms, int n, vector<int>& visited) {
        visited[n] = 1;

        for (int x : rooms[n]) {
            if (visited[x] == 0) {
                dfs(rooms, x, visited);
            }
        }
    }

    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        int n = rooms.size();
        vector<int> visited(n, 0);

        dfs(rooms, 0, visited);

        for (int m : visited) {
            if (m == 0) return false;
        }

        return true;
    }
};
```

## 数据范围

- `n == rooms.length`
- `2 <= n <= 1000`
- `0 <= rooms[i].length <= 1000`
- `1 <= sum(rooms[i].length) <= 3000`
- `0 <= rooms[i][j] < n`
- 同一个房间内的钥匙编号互不重复

## 复杂度

设钥匙总数为 `m`：

- 时间复杂度：`O(n + m)`
- 空间复杂度：`O(n)`，用于访问标记和 DFS 调用栈。
