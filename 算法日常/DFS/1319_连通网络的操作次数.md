# 1319. 连通网络的操作次数

- 难度：中等
- 主题：DFS、图、连通分量、邻接表
- [官方题目](https://leetcode.cn/problems/number-of-operations-to-make-network-connected/)

## 题目描述

有 `n` 台计算机，编号为 `0` 到 `n - 1`。数组 `connections` 中的每一项 `[a, b]` 表示计算机 a 与 b 之间已有一条网线。

一次操作允许拆下一条已有网线，并将它连接到两台此前没有直接相连的计算机之间。求使全部计算机处于同一连通网络所需的最少操作次数；如果网线总数不足以完成连接，返回 `-1`。

## 关键结论

要使 `n` 个节点全部连通，至少需要 `n - 1` 条边：

- 若 `connections.size() < n - 1`，无论怎样重连，网线总数都不够，直接返回 `-1`；
- 否则，设初始网络有 `count` 个连通分量，将每两个分量合并一次即可减少一个分量，因此最少操作数为 `count - 1`。

## 案例

### 案例 1

```text
n = 4
connections = [[0,1], [0,2], [1,2]]
```

结果：`1`。

说明：0、1、2 构成一个连通分量，其中存在可重用的边；将一条网线改接到节点 3，即可让全部节点连通。

### 案例 2

```text
n = 6
connections = [[0,1], [0,2], [0,3], [1,2], [1,3]]
```

结果：`2`。

说明：初始共有 3 个连通分量，需要用两次操作把它们合并为一个。

### 案例 3

```text
n = 6
connections = [[0,1], [0,2], [0,3], [1,2]]
```

结果：`-1`。

说明：只有 4 条网线，小于连通 6 个节点所需的最少 5 条网线。

### 案例 4

```text
n = 5
connections = [[0,1], [0,2], [3,4], [2,3]]
```

结果：`0`。

说明：所有节点本来就处于同一个连通分量。

## 我的解答：邻接表 DFS

代码先把边列表转换为无向图邻接表，再用 DFS 统计连通分量数量。满足网线数量条件时，返回连通分量数减一。

```cpp
class Solution {
public:
    void dfs(vector<vector<int>>& graph, int x, vector<int>& visited) {
        visited[x] = 1;

        for (int m : graph[x]) {
            if (visited[m] == 0) {
                dfs(graph, m, visited);
            }
        }
    }

    int makeConnected(int n, vector<vector<int>>& connections) {
        if (connections.size() < n - 1) return -1;

        int count = 0;
        vector<vector<int>> graph(n);
        vector<int> visited(n, 0);

        for (auto& e : connections) {
            int u = e[0];
            int v = e[1];
            graph[u].push_back(v);
            graph[v].push_back(u);
        }

        for (int i = 0; i < n; i++) {
            if (visited[i] == 0) {
                count++;
                dfs(graph, i, visited);
            }
        }

        return count - 1;
    }
};
```

## 数据范围

- `1 <= n <= 10^5`
- `1 <= connections.length <= min(n × (n - 1) / 2, 10^5)`
- 每条连接包含两个不同的合法计算机编号
- 不存在重复连接

## 复杂度

设 `m = connections.length`：

- 时间复杂度：`O(n + m)`
- 空间复杂度：`O(n + m)`，用于邻接表、访问数组和递归调用栈。
