# 547. 省份数量

- 难度：中等
- 主题：图论、DFS、连通分量
- [官方题目](https://leetcode.cn/problems/number-of-provinces/)

## 题目描述

有 `n` 个城市。有些城市直接相连；如果城市 A 与 B 直接相连、B 与 C 直接相连，那么 A 与 C 也属于同一个连通集合。

一个省份就是一个极大的连通城市集合：集合内任意两座城市可以直接或间接到达，集合外的城市不与该集合连通。

输入 `n × n` 矩阵 `isConnected`：

- `isConnected[i][j] = 1`：城市 i 与 j 直接相连；
- `isConnected[i][j] = 0`：城市 i 与 j 不直接相连。

返回省份总数，也就是无向图的连通分量数。

## 案例

### 案例 1

```text
isConnected = [[1,1,0],
               [1,1,0],
               [0,0,1]]
```

结果：`2`。

说明：城市 0 与 1 属于同一省份；城市 2 自成一个省份。

### 案例 2

```text
isConnected = [[1,0,0],
               [0,1,0],
               [0,0,1]]
```

结果：`3`。

说明：任意两座不同城市都不相连，因此每座城市各自构成一个省份。

## 邻接矩阵与邻接表

本题直接给出的 `isConnected` 是**邻接矩阵**，你的代码也按邻接矩阵进行遍历。

| 项目 | 邻接矩阵 | 邻接表 |
| --- | --- | --- |
| 表示方法 | `matrix[u][v]` 记录 u、v 是否存在边 | `graph[u]` 保存 u 的所有相邻节点 |
| 查一条边是否存在 | `O(1)` | 通常为 `O(deg(u))` |
| 枚举某节点全部邻居 | `O(n)`，需扫描整行 | `O(deg(u))` |
| 存储空间 | `O(n²)` | `O(n + m)` |
| 更适合的图 | 稠密图，或题目本身给矩阵 | 稀疏图，常见的边列表输入 |

在本题中，`isConnected[x][mm]` 直接判断城市 x 和 mm 是否相连；因此 DFS 时必须枚举矩阵第 x 行的所有 `n` 个位置。若输入改为边列表，通常会先构造邻接表，再只遍历实际相邻的城市。

## 我的解答：DFS

依次检查每座城市。遇到未访问城市时，将省份数量加一，并从该城市开始 DFS，将它所在连通分量的所有城市标记为已访问。

```cpp
class Solution {
public:
    void dfs(vector<vector<int>>& isConnected, int x, vector<int>& visited) {
        visited[x] = 1;
        int nn = isConnected.size();

        for (int mm = 0; mm < nn; mm++) {
            if (isConnected[x][mm] == 1 && visited[mm] == 0) {
                dfs(isConnected, mm, visited);
            }
        }
    }

    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<int> visited(n, 0);
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (visited[i] == 0) {
                count++;
                dfs(isConnected, i, visited);
            }
        }

        return count;
    }
};
```

## 数据范围

- `1 <= n <= 200`
- `isConnected` 是 `n × n` 的 0/1 矩阵
- `isConnected[i][i] = 1`
- `isConnected[i][j] = isConnected[j][i]`

## 复杂度

- 时间复杂度：`O(n²)`。每次 DFS 访问一个城市都需要扫描矩阵的一整行。
- 空间复杂度：`O(n)`，用于访问数组和递归调用栈；输入邻接矩阵本身占 `O(n²)`。
