# 1971. 寻找图中是否存在路径

- 难度：简单
- 主题：DFS、图、连通性
- [官方题目](https://leetcode.cn/problems/find-if-path-exists-in-graph/description/)

## 题目描述

给定一个包含 `n` 个顶点的**无向图**。顶点编号从 `0` 到 `n - 1`。

数组 `edges` 描述图中的边：`edges[i] = [u, v]` 表示顶点 `u` 和 `v` 可以双向到达。图中不会有自环，也不会有重复边。

给定起点 `source` 和终点 `destination`，判断能否从起点沿若干条边到达终点：

- 可以到达时返回 `true`；
- 无法到达时返回 `false`。

## 案例

### 案例 1

```text
n = 3
edges = [[0,1], [1,2], [2,0]]
source = 0
destination = 2
```

结果：`true`。

说明：0 与 2 之间可以直接到达，也可以经过顶点 1 到达。

### 案例 2

```text
n = 6
edges = [[0,1], [0,2], [3,5], [5,4], [4,3]]
source = 0
destination = 5
```

结果：`false`。

说明：0 所在的连通分量只包含 0、1、2；5 位于另一个连通分量中。

## 数据范围

- `1 <= n <= 2 × 10^5`
- `0 <= edges.length <= 2 × 10^5`
- 每条边恰好包含两个顶点编号
- `0 <= u, v < n` 且 `u != v`
- `0 <= source, destination < n`
- 不存在重复边或自环

## 我的解答：DFS

先用邻接表构建无向图，再从 `source` 开始深度优先遍历。遍历结束后，如果 `destination` 已被访问，说明两点连通。

```cpp
class Solution {
public:
    void dfs(int u, vector<vector<int>>& graph, vector<bool>& visited) {
        visited[u] = true;
        for (int v : graph[u]) {
            if (!visited[v]) dfs(v, graph, visited);
        }
    }

    bool validPath(int n, vector<vector<int>>& edges, int source, int destination) {
        vector<vector<int>> graph(n);

        for (auto& e : edges) {
            int u = e[0];
            int v = e[1];
            graph[u].push_back(v);
            graph[v].push_back(u);
        }

        vector<bool> visited(n, false);
        dfs(source, graph, visited);

        if (visited[destination] == true) return true;
        else return false;
    }
};
```

- 时间复杂度：`O(n + m)`，其中 `m = edges.length`。
- 空间复杂度：`O(n + m)`，用于邻接表、访问数组和 DFS 调用栈。
