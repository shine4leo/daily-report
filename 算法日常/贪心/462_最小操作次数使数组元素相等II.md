# 462. 最小操作次数使数组元素相等 II

- 题目链接：[LeetCode 462](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)
- 标签：贪心、排序、中位数
- 状态：已完成

## 题意

给定整数数组 `nums`。每次操作可以将任意一个元素加 `1` 或减 `1`；求使所有元素相等所需的最少操作次数。

## 思路：所有元素变为中位数

假设最终都变成值 `x`，操作次数就是：

```text
|nums[0] - x| + |nums[1] - x| + ... + |nums[n - 1] - x|
```

绝对值距离之和在 `x` 取数组的**中位数**时最小。因此：

1. 对数组排序。
2. 取中间位置的元素作为中位数。
3. 累加每个元素与中位数的绝对差。

当元素个数为偶数时，两个中位数之间的任意整数都能取得最小值；代码取右侧中位数同样正确。

## 代码

```cpp
class Solution {
public:
    int minMoves2(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        int n = nums.size();
        int median = nums[nums.size() / 2];

        int count = 0;
        for (int x : nums) {
            count += abs(x - median);
        }

        return count;
    }
};
```

## 复杂度

- 时间复杂度：`O(n log n)`，排序占主要时间。
- 空间复杂度：`O(log n)`，取决于排序实现的递归栈；不额外创建数组。

## 易错点

- 目标值应取**中位数**，不是平均数。
- 题目保证答案在 32 位整数范围内，因此 `int` 可以保存最终答案；若题目没有此保证，累计变量建议使用 `long long`。
