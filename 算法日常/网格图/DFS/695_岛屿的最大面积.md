# 695. 岛屿的最大面积

- 难度：中等
- 主题：网格图、DFS、连通块
- [官方题目](https://leetcode.cn/problems/max-area-of-island/description/)

## 题目描述

给定仅包含 `0` 和 `1` 的 `m × n` 网格：

- `1` 表示陆地；
- `0` 表示水域。

岛屿由上下左右方向连通的陆地组成。岛屿面积等于该连通块中陆地单元格的数量。

返回网格中最大的岛屿面积；如果不存在陆地，则返回 `0`。

## 案例

### 案例 1

输入为一个包含多个陆地区域的网格，最大的连通陆地区域有 6 个单元格。

结果：`6`。

注意：只允许上下左右连通，对角线相邻的陆地不能归入同一座岛屿。

### 案例 2

```text
grid = [[0,0,0,0,0,0,0,0]]
```

结果：`0`。

说明：网格中没有任何陆地。

## 我的解答：原地 DFS 累计面积

每次遇到陆地 `1` 时，从该位置开始 DFS：

1. 将当前格子改为 `0`，表示已访问；
2. 递归计算四个方向的陆地面积；
3. 当前面积等于 `1 +` 四个方向递归结果之和。

遍历所有岛屿，维护其中的最大面积。

```cpp
class Solution {
public:
    int dfs(vector<vector<int>>& grid, int x, int y) {
        int m = grid.size();
        int n = grid[0].size();

        if (x < 0 || x >= m || y < 0 || y >= n) {
            return 0;
        }

        if (grid[x][y] != 1) {
            return 0;
        }

        grid[x][y] = 0;

        int sum = 1;  // 当前格子本身面积为 1
        sum += dfs(grid, x - 1, y);
        sum += dfs(grid, x + 1, y);
        sum += dfs(grid, x, y - 1);
        sum += dfs(grid, x, y + 1);

        return sum;
    }

    int maxAreaOfIsland(vector<vector<int>>& grid) {
        int count = 0;
        int max1 = 0;
        int m = grid.size();
        int n = grid[0].size();
        vector<int> res;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    count++;
                    int x = dfs(grid, i, j);
                    max1 = max(x, max1);
                }
            }
        }

        return max1;
    }
};
```

## 数据范围

- `1 <= m, n <= 50`
- `grid[i][j]` 为 `0` 或 `1`

## 复杂度

设网格大小为 `m × n`：

- 时间复杂度：`O(mn)`，每个单元格最多访问一次。
- 空间复杂度：`O(mn)`，最坏情况递归调用栈包含全部陆地。
