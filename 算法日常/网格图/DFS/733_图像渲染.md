# 733. 图像渲染

- 难度：简单
- 主题：网格图、DFS、Flood Fill
- [官方题目](https://leetcode.cn/problems/flood-fill/)

## 题目描述

给定 `m × n` 的整数矩阵 `image`。每个单元格的值表示像素颜色。

从起点 `(sr, sc)` 开始，将与起点**上下左右四个方向连通**、且原始颜色相同的所有像素，全部修改为新颜色 `color`。返回修改后的矩阵。

对角线方向不算连通，因此两个相同颜色的像素若只在对角线上接触，不会被同时染色。

## 案例

### 案例 1

```text
image = [[1,1,1],
         [1,1,0],
         [1,0,1]]
sr = 1, sc = 1, color = 2
```

结果：

```text
[[2,2,2],
 [2,2,0],
 [2,0,1]]
```

说明：从中心像素出发，所有四方向连通的 1 都改为 2。右下角的 1 只与起点区域斜对角接触，保持不变。

### 案例 2

```text
image = [[0,0,0],
         [0,0,0]]
sr = 0, sc = 0, color = 0
```

结果不变，仍为原矩阵。

## 我的解答：原地 DFS 染色

递归函数处理当前像素时依次检查：

1. 是否越界；
2. 当前颜色是否仍等于起始颜色；
3. 满足条件时立刻改成新颜色，再向四个方向继续 DFS。

`oldColor == color` 时必须直接返回，否则当前像素改色后仍满足“颜色等于旧颜色”，会在相邻单元格间无限递归。

```cpp
class Solution {
public:
    void dfs(vector<vector<int>>& image, int x, int y, int oldColor, int color) {
        int m = image.size();
        int n = image[0].size();

        if (x < 0 || x >= m || y < 0 || y >= n) return;
        if (image[x][y] != oldColor) return;

        image[x][y] = color;

        dfs(image, x - 1, y, oldColor, color);
        dfs(image, x, y - 1, oldColor, color);
        dfs(image, x + 1, y, oldColor, color);
        dfs(image, x, y + 1, oldColor, color);
    }

    vector<vector<int>> floodFill(vector<vector<int>>& image, int sr, int sc, int color) {
        int oldColor = image[sr][sc];

        if (oldColor == color) return image;

        dfs(image, sr, sc, oldColor, color);
        return image;
    }
};
```

## 数据范围

- `1 <= m, n <= 50`
- `0 <= image[i][j], color < 2^16`
- `0 <= sr < m`
- `0 <= sc < n`

## 复杂度

设矩阵大小为 `m × n`：

- 时间复杂度：`O(mn)`，每个像素最多访问一次。
- 空间复杂度：`O(mn)`，最坏情况下递归调用栈包含全部像素。
