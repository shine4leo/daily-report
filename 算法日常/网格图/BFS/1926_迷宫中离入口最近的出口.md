# 1926. 迷宫中离入口最近的出口

- 题目链接：[LeetCode 1926](https://leetcode.cn/problems/nearest-exit-from-entrance-in-maze/)
- 标签：网格图、BFS、最短路
- 状态：已完成

## 思路

从入口开始做 BFS。队列按距离从近到远扩展，每次向上下左右四个方向尝试移动：

1. 越界、墙壁（`+`）或已访问的位置跳过。
2. 用 `dis` 记录入口到每个格子的距离，`-1` 表示未访问。
3. 新格子第一次入队时设置距离。
4. 如果新格子位于边界，它就是最近出口，直接返回距离。

入口本身即使在边界也不能算出口。这里从入口向外扩展后才检查新格子，因此不会把入口误判成出口。

BFS 按距离从近到远访问格子；每一步移动代价都为 1，所以首次发现的出口一定是距离最近的出口之一。

## 代码

```cpp
class Solution {
public:
    int nearestExit(vector<vector<char>>& maze, vector<int>& entrance) {
        int m = maze.size();
        int n = maze[0].size();

        queue<pair<int, int>> q;

        int dirs[4][2] = {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        q.push({entrance[0], entrance[1]});

        // dis[x][y]：入口到 (x, y) 的最短距离；-1 表示未访问
        vector<vector<int>> dis(m, vector<int>(n, -1));
        dis[entrance[0]][entrance[1]] = 0;

        while (!q.empty()) {
            auto [x, y] = q.front();
            q.pop();

            // 上下左右搜索 BFS
            for (auto [dx, dy] : dirs) {
                int nx = x + dx;
                int ny = y + dy;

                if (nx < 0 || nx >= m || ny < 0 || ny >= n) {
                    continue;
                }
                if (maze[nx][ny] == '+') {
                    continue;
                }
                if (dis[nx][ny] != -1) {
                    continue;
                }

                // BFS 按距离从近到远搜索，首次到达出口就是最近出口
                dis[nx][ny] = dis[x][y] + 1;

                if (nx == 0 || nx == m - 1 || ny == 0 || ny == n - 1) {
                    return dis[nx][ny];
                }

                q.push({nx, ny});
            }
        }

        return -1;
    }
};
```

## 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`
