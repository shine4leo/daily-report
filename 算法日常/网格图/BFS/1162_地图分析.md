# 1162. 地图分析

- 题目链接：[LeetCode 1162](https://leetcode.cn/problems/as-far-from-land-as-possible/)
- 标签：网格图、BFS、多源 BFS、最短路
- 状态：已完成

## 题意转化

题目要求“离所有陆地最远的海洋格子”到最近陆地的距离。

如果对每个海洋格子单独做一次 BFS，会重复搜索。更好的做法是：

> 把**所有陆地**都视为起点，同时入队，从它们向海洋一层层扩散。

这样每个海洋格子第一次被访问时，得到的就是它到**最近陆地**的最短距离；扩散到的最远一层就是答案。

## 多源 BFS 与单源 BFS 的区别

| 单源 BFS | 多源 BFS |
| --- | --- |
| 一个起点入队 | 所有起点同时入队 |
| 距离从一个起点向外扩散 | 距离从多个起点同时向外扩散 |
| 求离某个起点的最短距离 | 求离最近起点的最短距离 |

本题中所有陆地的 `dis` 都初始化为 `0`。队列初始状态可以理解为“第 0 层有所有陆地”；随后第 1 层是离最近陆地距离为 1 的海洋，第 2 层同理。

## 通用模板：多源 BFS

```cpp
constexpr int DIRS[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

// sources：所有起点；每个起点距离均为 0
vector<vector<int>> multiSourceBfs(
    int m,
    int n,
    const vector<pair<int, int>>& sources
) {
    vector dis(m, vector<int>(n, -1));
    queue<pair<int, int>> q;

    // 1. 所有源点同时入队
    for (auto [x, y] : sources) {
        dis[x][y] = 0;
        q.emplace(x, y);
    }

    // 2. 按层扩散
    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (auto [dx, dy] : DIRS) {
            int nx = x + dx, ny = y + dy;
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) {
                continue;
            }
            if (dis[nx][ny] != -1) {
                continue;
            }

            // 第一次到达就是离最近源点的最短距离
            dis[nx][ny] = dis[x][y] + 1;
            q.emplace(nx, ny);
        }
    }

    return dis;
}
```

## 解题思路

1. 遍历网格，将所有陆地（`1`）的距离置为 `0`，并全部入队。
2. 初始化 `ans = -1`。
3. 进行 BFS：每次访问一个尚未访问的相邻海洋，把距离设为当前格子距离加一。
4. 每产生一个新的海洋距离，就更新 `ans`。
5. BFS 结束后，`ans` 是最远海洋到最近陆地的距离。

### 为什么不用区分“从哪块陆地扩散”？

所有陆地都在初始时刻入队，BFS 队列始终按距离非递减的顺序处理格子。一个海洋格子第一次被任意陆地的扩散波访问时，必然来自距离它最近的陆地；后面更远的波不会再覆盖它。

### 边界情况

- **全是陆地**：没有海洋可以扩散，`ans` 保持 `-1`。
- **全是海洋**：初始队列为空，`ans` 保持 `-1`。
- 因此不需要额外判断，当前代码自然覆盖这两种情况。

## 代码

```cpp
class Solution {
public:
    int maxDistance(vector<vector<int>>& grid) {
        int n = grid.size();
        queue<pair<int, int>> q;
        vector<vector<int>> dis(n, vector<int>(n, -1));

        int dirs[4][2] = {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        // 多源 BFS：所有陆地都是距离为 0 的起点
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j] == 1) {
                    dis[i][j] = 0;
                    q.push({i, j});
                }
            }
        }

        int ans = -1;

        while (!q.empty()) {
            auto [x, y] = q.front();
            q.pop();

            for (auto [dx, dy] : dirs) {
                int nx = x + dx;
                int ny = y + dy;

                if (nx < 0 || nx >= n || ny < 0 || ny >= n) {
                    continue;
                }
                if (dis[nx][ny] != -1) {
                    continue;
                }

                dis[nx][ny] = dis[x][y] + 1;
                ans = max(ans, dis[nx][ny]);
                q.push({nx, ny});
            }
        }

        return ans;
    }
};
```

## 复杂度

- 时间复杂度：`O(n^2)`。每个格子至多入队、出队一次。
- 空间复杂度：`O(n^2)`。距离数组和队列最坏都需要存储 `n^2` 个格子。
